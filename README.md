O que é Inteligência Artificial?
A Inteligência Artificial é um conjunto de tecnologias capazes de executar tarefas que normalmente exigiriam inteligência humana, como reconhecer imagens, compreender textos, responder perguntas, tomar decisões e aprender com dados.

Dependência de dados.

Glossário
IA: tecnologia que simula inteligência humana.
Machine Learning: aprendizado por meio de dados.
Deep Learning: técnica baseada em redes neurais profundas.
Algoritmo: sequência de instruções para resolver um problema.
IA Generativa: IA capaz de criar textos, imagens, códigos e outros conteúdos.
